# Логика игры: 
Игра на сопоставление картинок заключается в том, что нужно игрок должен найти парные изображения среди всех карточек. 
Цель игры - найти все пары одинаковых изображений за минимальное количество ходов. 
За ход считается  выбор двух карточек для проверки совпадений. После запуска игрок видит поле из 16 ячеек, в начале игры содержимое всех карточек скрыто от пользователя. Пользователь выбирает закрытую карточку и нажимает на нее.  Карточка переворачивается и игрок видит изображение. Далее пользователь выбирает вторую закрытую карточку. Если изображение на двух этих карточка совпало, то они фиксируются в открытом виде и считаются найденной парой. Если же они не совпали, то через короткий промежуток времени карточки закрываются. Пользователь продолжает открывать карточка, пока не найдет все совпадающие пары. Игра считается завершенной, когда найдены все пары. Игрок увидит сообщение о завершении игры.
